# Contigo unDraw illustrations

Drop SVGs from [unDraw](https://undraw.co) into this folder.

Expected filenames (wired in `src/data/contigo.tsx`):

| File | Card |
|------|------|
| `goal.svg` | Goal |
| `opportunity.svg` | Opportunity |
| `challenge.svg` | Challenge |
| `outcome.svg` | Outcome |

These replace the old process photos on the card face.
Process artifacts still live under `../process/` and only
appear inside each card’s expanded panel.
