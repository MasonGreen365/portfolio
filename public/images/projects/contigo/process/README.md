# Contigo process images

Drop design-process photos and exports in this folder.

They are served at:

`/images/projects/contigo/process/<filename>`

## Naming

Prefer numbered prefixes so gallery order stays stable:

- `01-...` research / problem framing
- `02-...` architecture / technical design
- `03-...` roadmap / planning
- `04-...` workshop / ideation
- `05-...` prototype / demo
- `09+` anything new you add later

See `contigo/CONTIGO_PROJECT_FINDINGS.md` for the full suggested list.

## Notes

- Redact client PII before uploading chat screenshots.
- Prefer PNG or WebP; compress large JPGs when you can.
